# CoMYAKU-typo-tool

CoMYAKU タイポグラフィツール  
万博デザインスタイルでテキストを生成できる非公式ツールです。  
※本ツールおよび生成物の利用については、利用者自身の責任でご使用ください。

## 使い方
1. `Comyaku-typo-tool.html` をダウンロード  
2. ブラウザで開くだけで利用可能です（インストール不要・ローカル動作）

## 注意事項
- ローカル環境での使用を推奨します  
- 公式ガイドライン参照：https://www.expo2025.or.jp/wp/wp-content/uploads/260330r2_designsystem-guideline.pdf

## v1.1.0 の変更点

### 新機能
- 縦書きモード（右から左の伝統配置）
- ライン別の伸縮（横幅%・縦幅%）・行間の個別設定
- 全体リセットボタン
- 線スタンプ（赤・青・灰）と消しゴムスタンプ
- スタンプの回転（8方向コンパス＋目線モード）
- 歪み加工（横/縦ウェーブ・膨らみ・ねじり）
- 加工の範囲指定（四角・丸、なじませ境界）
- 加工の重ねがけ（背景ごと確定／文字のみ確定）
- 背景画像の取り込み（位置・拡大調整可）
- 文字の白フチ ON/OFF
- タッチ操作対応（スマホでのスタンプ操作）

### 変更
- 3色カラーモードをランダムから順番（赤→青→灰）に変更
