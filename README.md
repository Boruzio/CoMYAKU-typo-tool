# CoMYAKU-typo-tool

CoMYAKU タイポグラフィツール  
万博デザインスタイルでテキストを生成できる非公式ツールです。  
※本ツールおよび生成物の利用については、利用者自身の責任でご使用ください。

## 使い方
1. `Comyaku-typo-tool.html` をダウンロード  
2. ブラウザで開くだけで利用可能です（インストール不要・ローカル動作）

## 注意事項
- ローカル環境での使用を推奨します  
- 公式ガイドライン参照：https://www.expo2025.or.jp/wp/wp-content/uploads/260330r2_designsystem-guideline.pdf
